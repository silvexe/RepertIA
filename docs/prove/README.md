# Prove su dati di riferimento pubblici · Tests against public reference data

RepertIA è stato messo alla prova su immagini pubbliche preparate da altri, con le risposte attese scritte da chi le ha
create. Le prove le abbiamo fatte noi: dati, metodo e [script](../../tools/prove/) sono pubblici perché chiunque possa
rifarle. Non è una certificazione: NIST e Joshua Hickman non hanno provato RepertIA.

*RepertIA was tested on public images prepared by others, with the expected answers written by their authors. We ran the
tests ourselves: data, method and [scripts](../../tools/prove/) are public so that anyone can repeat them. This is not a
certification: NIST and Joshua Hickman did not test RepertIA.*
